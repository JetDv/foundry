# Templates

Blank starters. New work is a copy, never a blank page.

Entry-file templates carry an `entry-` prefix, dropped when the file is copied to its destination. The reason is in `../_shared/conventions.md`, What never gets created.

| Template | Copied to | Used by |
|---|---|---|
| `brief.md` | `stages/01_interview/output/brief.md` | 01 |
| `blueprint.md` | `stages/02_blueprint/output/blueprint.md` | 02 |
| `entry-AGENTS.md` | emitted workspace `AGENTS.md` | 03 |
| `entry-CLAUDE.md` | emitted workspace `CLAUDE.md` | 03 |
| `root-CONTEXT.md` | emitted workspace `CONTEXT.md` | 03 |
| `stage-CONTEXT.md` | emitted workspace `stages/NN_*/CONTEXT.md` | 03 |
| `questionnaire.md` | emitted workspace `setup/questionnaire.md` | 03 |
| `library-record.md` | `library/{slug}.md` | 04 |
